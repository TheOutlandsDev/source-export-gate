# Origins and review limits

This project combines the OUTLANDS Source Export Gate v0.9 intake builder and
v0.10 read-only intake verifier, with earlier eligibility/receipt/coverage helpers.
Implementation, synthetic tests and documentation were developed with AI assistance
for TheOutlandsDev. Existing production bodies are preserved. Packaging makes the
scanner test fixture package-local and uses plainly synthetic test paths. The
portable combined test runner adapts the earlier private runner.

The bundled scanner is an exact copy of the publicly available preupload-check
helper described in THIRD-PARTY-NOTICES.md, with its MIT notice preserved. A bounded
filename/name search found no additional indexed matches. This is limited matching
coverage, not proof of originality or ownership.

No runtime histories, review receipts, inventories, private terms or real data are
included. The project MIT license grants no rights in source files reviewed with
the tool. Tests and privacy screens never grant approval to publish those files.
